# Afectivalab — ilustraciones de personajes

Diez PNG cuadrados con transparencia alfa real, generados con la herramienta integrada imagegen según la sección 5 del documento. Incluye las siete ilustraciones principales y los tres avatares opcionales.

- hero-familia.png: 1600 × 1600 px, reescalada desde 1254 × 1254 mediante sips. El original se conserva en originales/. El reescalado no añade detalle nativo.
- Cinco etapas, caso práctico y tres avatares: 1254 × 1254 px nativos.
- prompts.json: prompts base aplicados; la familia se usó como referencia de estilo para las otras nueve piezas. Se reforzaron transparencia, formato cuadrado, márgenes y diferencias de edad/apariencia.
- manifest.json: dimensiones verificadas y procedencia de resolución.
- galeria.html: vista conjunta con selector de fondo para revisar la transparencia.

Son ilustraciones rasterizadas, no SVG. Las sombras generadas tienen transiciones suaves además del sombreado por planos. Los nombres coinciden con los sugeridos en el documento. Este paquete entrega los archivos; no modifica el tema ni los logos e iconos aprobados.
